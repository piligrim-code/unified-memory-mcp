# Contributing

Keep changes within the supported public scope described in README.md.
Include a small synthetic regression test and run the documented test command.
Do not add credentials, personal paths, private reports or downloaded datasets.
For numerical changes, record the baseline, seed, tolerances and limitations;
do not convert a negative result into a passing claim by adjusting thresholds.

The public source manifest identifies the private-development commit used to
prepare this snapshot. It contains hashes and paths, not the original history.
The private repository and this bounded public snapshot have different scopes.
