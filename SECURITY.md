# Security and scope

This repository is a local open-source candidate, not a hosted service.
No secret, credential, user database or production configuration is included.

Do not post credentials, private datasets, database files, transcripts or raw
incident logs in public issues. Share only a minimal synthetic reproducer.
Private vulnerability reporting requires a maintainer-approved private channel;
none is provisioned automatically by this source snapshot.

Dependency wheels, model weights and third-party datasets are not redistributed.
Their licenses and terms remain separate from the project license.
Run untrusted inputs in an isolated environment. Passing tests is not a security
certification, independent scientific replication or approval for production use.
